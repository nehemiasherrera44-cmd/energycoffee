jQuery

Una biblioteca de JavaScript que simplifica la interacción con la página.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para simplificar tareas frecuentes del desarrollo web.

Permite seleccionar elementos HTML, manejar eventos y crear efectos con poco código.

Sintaxis básica

Casi todo empieza con el símbolo $, que selecciona elementos de la página.

$("#mensaje").hide();
$("#mensaje").show();

Ventajas y desventajas

Ventajas

  • Sintaxis sencilla.
  • Facilita algunas tareas.
  • Crea efectos fácilmente.

Desventajas

  • Necesita una biblioteca externa.
  • JavaScript moderno ya ofrece alternativas.
  • No siempre hace falta en proyectos nuevos.
