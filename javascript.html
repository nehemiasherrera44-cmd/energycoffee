JavaScript

El lenguaje que da vida a una página: responde a lo que hace el usuario.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que se usa sobre todo para crear páginas web interactivas.

Con él, una página puede reaccionar a las acciones del usuario, modificar elementos y ejecutar funciones.

Variables

Una variable guarda un dato para usarlo más adelante en el programa.

let nombre = "Energy Coffee";
let precio = 2.50;

Funciones

Una función es un bloque de código que hace una tarea concreta y se puede llamar cuando se necesite.

function saludar() {
    alert("¡Bienvenido a Energy Coffee!");
}

Eventos

Un evento es algo que ocurre en la página, como un clic. Con JavaScript se puede ejecutar código cuando pasa.

boton.onclick = function() {
    alert("Has presionado el botón");
};
