JavaScript

Lenguaje utilizado para agregar interactividad y comportamiento a las páginas web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas.

Permite responder a las acciones de los usuarios, modificar elementos y crear diferentes funciones.

Variables

Las variables permiten guardar información que puede utilizarse durante la ejecución de un programa. 


let nombre = "Energy Coffee";
let precio = 2.50;

Funciones

Una función es un bloque de código que realiza una tarea específica. 


function saludar() {

    alert("¡Bienvenido a Energy Coffee!");

}

Eventos

Los eventos permiten ejecutar acciones cuando el usuario realiza alguna actividad en la página. 


button.onclick = function() {

    alert("Has presionado el botón");

};
