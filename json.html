JSON

Un formato utilizado para almacenar e intercambiar datos.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para almacenar y transportar información.

Es muy utilizado en aplicaciones web para intercambiar información entre un cliente y un servidor.

Pares clave-valor

JSON utiliza pares de clave y valor para organizar la información. 


{
    "nombre": "Energy Coffee",
    "precio": 2.50,
    "disponible": true
}

Objeto JavaScript 


const producto = {
    nombre: "Energy Coffee",
    precio: 2.50
};

Cadena JSON 


{
    "nombre": "Energy Coffee",
    "precio": 2.50
}

Objetos y arreglos

JSON también puede contener arreglos, los cuales permiten guardar varios elementos dentro de una misma estructura. 


{
    "productos": [
        "Energy Coffee",
        "Coffee Classic",
        "Coffee Latte"
    ]
}

JSON en las aplicaciones web

Una aplicación web puede solicitar información a un servidor. El servidor puede responder utilizando JSON y JavaScript puede utilizar esos datos para mostrarlos en la página.

↓
📡 Solicitud
↓
🖥️ Servidor
↓
📦 Datos JSON
↓
🌐 Página web
