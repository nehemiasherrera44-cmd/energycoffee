JSON

Un formato de texto para guardar e intercambiar datos.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto para guardar y transportar información.

Se usa mucho en aplicaciones web para que un cliente y un servidor se pasen datos.

Pares clave-valor

JSON organiza la información en pares: una clave y su valor.

{
    "nombre": "Energy Coffee",
    "precio": 2.50,
    "disponible": true
}

Objeto de JavaScript y cadena JSON

Se parecen, pero no son lo mismo. En JSON las claves siempre van entre comillas.

Objeto de JavaScript

const producto = {
    nombre: "Energy Coffee",
    precio: 2.50
};

Cadena JSON

{
    "nombre": "Energy Coffee",
    "precio": 2.50
}

Objetos y arreglos

Un arreglo guarda varios elementos dentro de una misma estructura.

{
    "productos": [
        "Energy Coffee",
        "Coffee Classic",
        "Coffee Latte"
    ]
}

JSON en una aplicación web

La página pide datos a un servidor, el servidor responde en JSON y JavaScript los muestra en pantalla.

  1. La página hace una solicitud
  2. El servidor recibe la solicitud
  3. El servidor responde con datos JSON
  4. La página muestra los datos
