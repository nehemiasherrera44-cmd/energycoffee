Hosting y Dominios

¿Cómo hacemos que una página web esté disponible en Internet?

¿Qué es Web Hosting?

Web Hosting es un servicio que permite almacenar los archivos de un sitio web en un servidor conectado a Internet.

Gracias al hosting, las personas pueden acceder a las páginas web desde diferentes dispositivos.

Tipos de Hosting

Hosting compartido

Varios sitios web utilizan los recursos de un mismo servidor.

VPS

Un servidor físico se divide en diferentes servidores virtuales.

Nube

Utiliza recursos de diferentes servidores conectados a través de Internet.

¿Qué es Vercel?

Vercel es una plataforma utilizada para desplegar sitios web y aplicaciones.

Puede conectarse con GitHub para publicar automáticamente un proyecto que se encuentra en un repositorio.

¿Qué es un dominio?

Un dominio es el nombre que se utiliza para identificar y acceder a un sitio web.

energycoffee.com

TLD

TLD significa dominio de nivel superior.

.com Comercial
.org Organizaciones
.net Redes

¿Qué es un subdominio?

Un subdominio es una parte adicional que aparece antes del dominio principal.

blog.energycoffee.com

Propagación DNS

El DNS permite encontrar la dirección asociada a un dominio. Cuando se realiza un cambio en los DNS, la información puede tardar un tiempo en actualizarse en diferentes servidores.
