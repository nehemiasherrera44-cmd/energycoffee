Hosting y dominios

Cómo hacer que una página web esté disponible en Internet.

¿Qué es el web hosting?

Es un servicio que guarda los archivos de un sitio web en un servidor conectado a Internet.

Gracias a eso, cualquier persona puede abrir el sitio desde su dispositivo.

Tipos de hosting

Compartido
Varios sitios web usan los recursos de un mismo servidor.
VPS
Un servidor físico se divide en varios servidores virtuales.
Nube
Usa los recursos de varios servidores conectados por Internet.

¿Qué es Vercel?

Vercel es una plataforma para publicar sitios web y aplicaciones.

Se conecta con GitHub y publica el proyecto automáticamente desde un repositorio.

Dominio y subdominio

Un dominio es el nombre con el que se identifica y se entra a un sitio web.

energycoffee.com

Un subdominio es una parte extra que va antes del dominio principal.

blog.energycoffee.com

TLD

TLD significa dominio de nivel superior: la terminación del dominio.

.comComercial
.orgOrganizaciones
.netRedes

Propagación DNS

El DNS encuentra la dirección asociada a un dominio. Si se cambia, la actualización puede tardar en llegar a todos los servidores.

  1. El usuario escribe el dominio
  2. El DNS busca la dirección
  3. Se conecta con el hosting
  4. Se muestra la página
