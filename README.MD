## 2. Investigación Técnica
1. **JavaScript (Vanilla):** Usado para validar el formulario y la interactividad del menú.
2. **jQuery:** Librería para simplificar animaciones del carrusel y selectores.
3. **JSON:** Guardamos los productos y preguntas del cuestionario en formato JSON.
4. **Web Hosting y Dominios:** Vercel aloja el sitio y gestiona el dominio vercel.app.

## 3. Integraciones Especiales
### Formulario de Contacto + Webhook de Discord
El formulario de contacto envía los datos mediante fetch() a la URL del Webhook de Discord, generando una notificación automática en el canal.
